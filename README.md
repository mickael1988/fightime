# Fightime

Timer sportif en web app (PWA) : Tabata, rounds de boxe/MMA, chronomètre et minuteurs personnalisés.

**👉 [Ouvrir l'app](https://mickael1988.github.io/fightime/)** — sur iPhone : Safari › Partager › « Sur l'écran d'accueil ».

## Fonctionnalités

- Modes Tabata, Rounds, Chronomètre et préréglages (Boxe, MMA, Muay Thaï, EMOM, AMRAP…)
- Éditeur d'intervalles : préparation, exercice, repos, rounds, cycles, repos entre cycles, récupération
- Minuteurs personnalisés sauvegardés
- Sonorités (gong, cloche de boxe, bip, sifflet, sirène), annonces vocales, décompte 3-2-1
- Thèmes Orange + Bleu et Citron + Violet, couleurs pâles, flash écran, vibration
- Fonctionne hors ligne, écran maintenu allumé pendant la séance

## Lancer en local

```sh
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.
